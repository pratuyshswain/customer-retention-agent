# Release readiness checklist

- [ ] Review and merge intended documentation and CI pull requests.
- [ ] Verify dependency installation and run the project checks in a clean environment.
- [ ] Build and smoke-test the container using synthetic or authorized data.
- [ ] Review credentials, dataset provenance, dependency vulnerabilities and generated artifacts.
- [ ] Confirm redistribution rights and licensing before publishing artifacts or images.
- [ ] Document actual changes, known limitations and verified results.
- [ ] Choose a version and tag only after maintainer approval.
- [ ] Publish release notes and verify the resulting artifact.

No release, tag, hosted deployment or support commitment is created by this checklist.
